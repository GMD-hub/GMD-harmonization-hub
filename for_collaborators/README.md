# For collaborators

This folder holds short, role specific guidance. Each file should be
readable by someone with no prior context on the project.

Planned files, not yet written:

- `its_infrastructure_overview.md`, a lay language summary of what the
  pipeline needs from infrastructure and why, for ITS.
- `regional_focal_point_guide.md`, what a harmonization rule needs to
  look like before it can be added to the CVS, for regional focal points.

Add files here as they are drafted. Keep each one short and specific to
one audience rather than trying to write one document for everyone.
